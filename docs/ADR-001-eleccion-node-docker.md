# ADR-001: Node + Docker + Postgres
 
## Estado
Aceptado
 
## Contexto
Para el hito M01 el equipo tenia que elegir el lenguaje de la aplicacion y
dejarlo documentado.
 
## Decision
El equipo (Ruben, David, Angeles) usa Node con el cliente pg para hablar
con Postgres, y Docker Compose (ya incluido en la base) para levantar la
base de datos.
 
## Por que
Los tres ya sabemos algo de Node y asi no se complica el proyecto con
herramientas nuevas.
